# 购物守护者 1.9.0 历史购买清单验收

## 本轮范围

- 在“习惯 → 我的物品”中增加历史购买清单批量录入。
- 支持竖线或制表符分隔，每行包含名称、分类、当前状态、价格、日期和备注。
- 价格、日期、备注可省略；省略状态时默认“买过，现状不确定”。
- 解析后必须经过逐条预览，可调整分类、状态或排除项目，再统一写入。
- 格式错误的行不可选择。
- 与本机已有物品、清单前序行同名同分类的项目默认排除。
- 批量保存先验证全部数据，再在单个数据库事务中写入。

## deep-grill 发现并修复

1. “买过”不能推导为“仍在用”，因此缺省状态不会进入当前拥有物品的模型上下文。
2. 不能把粘贴文本直接写库，因此增加独立预览确认步骤。
3. 第一版只检查本机冲突，遗漏清单内部重复；复审后增加清单内动态去重。
4. 批量保存不能写到一半失败，因此先验证所有行，再开启事务。
5. 小屏标题区可能挤压，操作入口改为可换行布局。

## 边界

- 本功能处理用户主动填写的历史事实，不尝试从店铺订单接口抓取数据。
- 未识别的自定义分类安全映射为“其他”，用户可在预览中调整。
- 本轮不包含截图 OCR；订单截图预览、编辑和去重属于下一项 ORDER-02。
