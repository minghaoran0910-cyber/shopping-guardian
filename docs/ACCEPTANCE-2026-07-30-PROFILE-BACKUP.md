# DATA-09 验收记录：消费人格备份与恢复

版本：1.10.0+35

## 数据格式

- JSON 业务备份版本从 8 升级到 9。
- `consumer_profile` 保存标题、三项特点、提醒、来源类型和更新时间。
- API Key、JustOneAPI Token 和模型鉴权信息仍不进入导出。

## 导入语义

- 导入预览会明确显示是否包含一份消费人格。
- 合并导入：本机已有消费人格时保留本机编辑；本机没有时导入备份。
- 覆盖导入新版备份：以备份为准；字段为 `null` 时删除本机人格。
- 覆盖导入 1–8 版旧备份：保留本机人格，因为旧格式无法表达用户是否希望删除。
- 格式无效、特点不足或字段越界时拒绝整份导入，不部分修改本机数据。

## 验证

- 定向导入导出测试覆盖导出、合并、覆盖、旧版兼容和非法格式拒绝。
- 导入仍在 Drift 事务内完成；任一写入失败会整体回滚。
