## 真实验收发现并修复

1. 常见 OpenAI 兼容 Base URL 未自动补全 `/chat/completions`，会把有效配置误报为接口不存在。
   - 修复：以 `/v1` 结尾时自动补全；完整地址和非标准路径保持不变。
2. 成功保存决策后首页仍保留上一件商品，存在误触重复分析风险。
   - 修复：只在决策成功落库后清空草稿；取消或失败时保留输入。
3. 用户提供的模型标识不在当前工作空间模型列表中。
   - 结论：应用保持明确失败，不静默替换；验收改用同系列实际可用的低成本模型。
4. 保存月预算后 debug 版触发 `setState` 返回 Future 的断言红屏。
   - 修复：把异步读取放在 `setState` 外，状态闭包只做同步赋值；预算输入控制器改由弹窗自身管理。
5. iOS 会把模型名 `qwen` 自动纠正为英文单词，导致配置看似正确、实际请求错误。
   - 修复：Base URL、API Key、模型名关闭自动纠错、联想和自动大写。
6. 只有引号内的标题会被分享解析器识别；部分系统分享或输入法会移除书名号。
   - 修复：在分享码后增加保守的单行标题回退解析，并过滤链接和平台操作说明。
7. 模型返回 `wait_days: 0` 时，用户手动选择“稍后再看”会得到 0 天冷静期。
   - 修复：非正数等待天数视为未指定，用户选择稍后时回退为 7 天。
8. 设置卡片使用有背景的 `DecoratedBox` 包裹 `ListTile`，debug 控制台报告水波纹可能不可见。
   - 修复：设置卡片改为带圆角裁剪的 `Material`，为列表项提供正确的绘制祖先。
9. 拼多多详情页的导航文本被 ML Kit 拆成独立文本块时，现有合并行用例无法阻止“店铺 / 收藏 / 客服 / 品牌”进入最终标题。
   - 修复：在最终标题形成后增加受限的拼多多导航前缀清洗，并新增分块 OCR 回归用例；Android 与 iOS 使用同一截图复验通过。
10. 安装包元数据已升级到 1.8.6，但设置页仍显示硬编码的 1.8.5。
    - 修复：同步应用版本常量，并运行版本常量与 `pubspec.yaml` 一致性测试，防止错误版本信息进入提交。
