# 细分类推荐 LOOP 验收

日期：2026-08-03

## 目标

消除“数码”这个粗分类把耳机、键盘、手机同时作为默认对照对象的噪声，同时保留旧数据与人工控制。

## 实现

- 已有物品新增可选 `itemType`，迁移数据库 Schema v8 → v9；旧物品保持空类型，不自动推断。
- 数码类型覆盖耳机/音频、键盘/鼠标、手机/平板、电脑、显示器/投影、相机/智能穿戴、网络/存储；服饰、家居、兴趣收藏、运动、美妆护理也提供常用类型。
- 添加/编辑物品可选择细分类；切换大类时清除不再适用的类型。
- 历史购买清单支持第七列“细分类”：`名称 | 分类 | 状态 | 价格 | 日期 | 备注 | 细分类`；不属于该分类的类型会安全忽略，等待用户编辑确认。
- 候选商品选择细分类后，仅自动预选相同类型的在用/备用物品；没有细分类时维持旧的按大类预选；任何结果都可由用户逐项调整。
- JSON 备份格式升级到 v10，继续兼容 v1–v9；导入和本地数据库写入均校验类型是否属于大类。

## 验收

- 数据库升级覆盖 v1 → v9 与已有 v6 表升级；不重复添加列。
- 物品库拒绝“家居 → 耳机/音频”这类跨分类类型。
- 清单解析保留有效的耳机/音频类型，丢弃不匹配类型。
- Widget 路径验证：新耳机只自动预选旧耳机，键盘必须由用户显式加入。
- `dart analyze lib test integration_test tool` 通过（0 个 issue）。
- 全量 Flutter 测试 218/218 通过（排除真机集成标签）。
- 本地 Release 构建通过：Android APK、macOS App、iOS Simulator App 均为 `1.10.3+38`；APK 已通过 v2 签名校验。
- GitHub Actions 三端均通过：Apple builds（#30789940550）、Android build（#30789940467）、Windows build（#30789940454）。
