# 购物守护者 1.8.7 验收记录

日期：2026-07-30

## 本轮目标

修复购物车多商品共用一条建议、一组分类和一个决定的问题。

## 已通过

- 导入预览可逐项排除不需要分析的商品。
- 多商品进入分析时只展示当前商品，并显示当前进度。
- 每件商品使用自己的价格、购买理由、预算、分类和标签。
- 中途返回后，尚未分析的商品仍留在预览；已完成的决定保持落库。
- 单商品导入流程保持不变。
- 149 项自动化测试全部通过。
- Dart 静态检查 0 问题。
- 新导入预览 Golden 基线已人工检查，没有按钮遮挡或文本溢出。
- Android Debug APK、iOS Simulator Debug 和 macOS Debug 构建成功。

## deep-grill 复审

- 最强失败场景是把不同类别的购物车商品合成一条历史，导致物品库、预算、偏好和后悔反馈都失真；本轮已从流程入口拆为逐件决策。
- 批量流程不做“全部成功才保存”的假事务：用户每完成一件就立即保存，取消时只停止后续项目。
- 仍未解决“用户当前拥有什么”和“真实历史低价从哪里来”。这两项已经拆进 P3/P4，不能把现有历史相似度描述成完整推荐系统。

## 后续

- 建立已有物品与历史订单事实层。
- 支持手工模板和订单截图导入，并区分仍在用、已淘汰、退货等状态。
- 候选商品与同分类已有物品对比。
- 价格结论必须带来源、时间和匹配置信度；缺少可靠数据时明确提示。
