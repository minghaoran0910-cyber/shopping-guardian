# 购物守护者 1.9.1 订单截图导入验收

## 本轮范围

- “习惯 → 我的物品 → 订单截图”通过系统图片选择器按次读取图片。
- Android 复用随安装包提供的 ML Kit 中文 OCR；iOS/macOS 复用 Apple Vision。
- 图片和 OCR 原文均不发送给模型，也不长期保存。
- 使用独立订单解析器配对疑似商品名称和单品价格。
- “实付款、合计、总计、订单金额、运费”等不会作为商品价格。
- 退款或退货状态只影响附近订单项目，不污染截图中的其他订单。
- 所有结果先进入预览，可修改名称、分类、状态、价格、日期和备注，也可排除。
- 与已有物品或同批前序记录同名同分类时默认排除，确认后才事务写入。

## deep-grill 发现并修复

1. 购物车与订单语义不同，不能直接把购物车解析结果写成购买历史，因此建立独立解析器。
2. “交易成功”只能证明买过，不能证明仍在使用；缺省状态固定为“买过，现状不确定”。
3. 初版预览只能修改分类和状态，不满足 OCR 错字修正需求；复审后补齐全部字段编辑。
4. 整张截图存在“退款成功”时不能把所有商品都标记退货；改为按最近订单状态判断。
5. 无法可靠配对名称和价格时明确失败，不编造订单项目。

## 已知边界

- OCR 结果依赖截图清晰度和平台排版，用户仍需核对。
- 当前采用商品名与价格的保守邻近配对，不解析订单号、店铺账户或收货信息。
- 分类无法由 OCR 可靠确定，默认“其他”，由用户在预览中选择。
