# 消费人格与价格监测修复验收

版本：1.9.9+34

## 消费人格

- 至少三条有有效决策来源的已确认偏好才会直接生成结果。
- 证据不足时使用四道本地趣味小题，不调用模型。
- 结果可编辑，并可保存为 PNG 分享卡。
- 分享载荷只允许标题、三个特点、提醒、娱乐性免责声明、应用名和项目地址。
- 分享卡不含商品、金额、订单、API Key 或模型配置，并明确说明不是心理测评或科学结论。

## 价格监测

- 参考 PriceDive 的定时采样、本地 SQLite 历史和趋势证据思路，不采用其默认模拟价格。
- 淘宝、京东单品由用户自行决定是否监测并设置目标价，报价继续来自用户配置的 JustOneAPI。
- 新建监测立即检查，修复“目标价已满足却因预填上次价格而漏掉首次提醒”的问题。
- 目标价可修改；修改会重置旧的穿越与通知状态并立即重新查询。
- 可信度不足的报价只留作诊断，不触发通知；目标价连续满足时不会重复轰炸。
- 通知文案为“可以考虑下单”，不替用户作最终购买决定。

## 自动性边界

应用会在创建、修改、手动点击检查、启动和回到前台时查询价格，自动检查最短间隔为六小时。纯本地移动应用不能承诺被系统关闭后仍 24 小时运行，界面与 README 已明确提示检查时间受系统后台策略限制。
